## ★★ 复刻任务：切分单位 = 台词句，不是镜

- ★★ **切短不省时间（2026-09-19 实测推翻旧结论）**：工作流有 **124 帧（5.167 s）渲染地板** ——
  见 `h3_t8/timing.py`：`ensure_minimum_context=True` → `required = max(required, MIN_TRAINED_FRAMES/FPS)`（124/24），
  补齐后送采样，成片再由 `MiniMaxH3OutputTrimT8` 裁回。**地板以下全是同一个价**。
  373 镜里 **348 镜（93.3 %）落在地板下**，付费帧 = 需要的 **1.94 倍**。

## ★ 会静默毁结果的坑（完整 17 条见 AGENTS.md §八）

- ★ **`http_proxy` 劫持 localhost**（最阴）：有 `HTTP_PROXY=…` 时 `curl http://127.0.0.1:8188/...` **走代理拿 502** → 检查脚本误报「ComfyUI 没响应」。
  自查：curl 返 502/000 但端口在监听。**解法 `export no_proxy="127.0.0.1,localhost,::1"`**（`NO_PROXY` 同设）；远程用前置赋值。★ **下载权重的脚本不能加**；`deploy/` 下 7 个脚本已内置。
- **`pkill -f <name>` 会匹配执行它的 ssh 命令行 → 自杀式断连**；用 `ps -eo pid,args | grep "[x]xx"` 拿 PID 再 kill。清队列用 `POST /queue {"clear":true}` + `POST /interrupt`。
- **zsh 不做单词切分**（`for x in $VAR` 整串当一个词）→ 用字面列表或 `${=VAR}`；**`cd X && A & B &` 里 B 跑在原 cwd** → 后台提交一律绝对路径。
- 工作流顶层不能有 `_meta`（报 `missing_node_type: ID #_meta`）；`SaveVideo.format/codec` 是动态 combo，白名单不认 → 参数静默消失；**`s2_adapt.py` 只吃 API 格式**（喂 UI 会静默不改造 + 谎报「已适配」）；权重路径要带 `text_encoders/minimax_h3/...`，放错根 → 400 `value_not_in_list`。
- ★ **门禁脏状态**（不报错，只静默跳过）：`gates*/<k>.lock` 残留 → 该镜**永久跳过**；`<k>.fail` = 失败过被跳过。接手前 `find gates* -maxdepth 1 -type d -name '*.lock' -exec rmdir {} \;`。

# 追加（2026-09-19 下午）· 参考帧零文字是硬门槛

## ★★ 参考帧有字 = 成片必抄（实测）

模型会把参考帧里的硬字幕**原样画进成片**（不是幻觉）。所以「参考帧零文字」是复刻的前置条件，不是优化项。
判别方法（`check_band.py`）：量字幕带 `edge = mean|Laplacian|` 与黄字像素占比，**参考帧带内偏高 = 泄漏**；
参考帧干净但成片有字 = 真幻觉。**先用这个分辨，别一律归给模型。**

## ★★ v3/v4 清洗漏检 9+ 帧（含 6 帧顽固）

`prep_refs_v3/v4` = `find_hits` 出框 → `stroke_mask` 框内取「亮字+深描边」→ `inpaint(NS)`。两个死穴：
1. **框漏/框歪** → 掩码没盖到字（报告里 `sub` 有命中，字还在）；
2. `stroke_mask` 掩码边界就是**字的黑描边** → `inpaint` 从边界取色 → **填成黑块**。

## ⛔ 已废弃：`rescrub_sub.py`（行带 866–986 的方案）——**它没解决问题，只把字涂成了"黄黑斑块"**

> 2026-09-19 傍晚复盘的结论：这一版被误判为"成功"。数值判据显示"列数归零"，
> 但**字形轮廓原样留在参考帧里**（inpaint 掩码边界落在黑描边上 → 从描边取色 → 黑斑+黄边），
> 下游模型照样把它复刻成字幕。**永远不要用"字还在不在"来自证清洗成功，必须看图。**

它错在哪（留档，别再犯）：
1. `STRIP=(866,986)` 只覆盖字幕**第二行**；抖音字幕常是**两行**（实测 dy3_s054：第一行 y 815–890、
   第二行 y 900–985）→ 第一行上半被切掉，残字被 inpaint 带成黄条；
2. 掩蔽带边界压在**黑描边**上 → 填充取到描边色；
3. 只处理"字幕"，**底部免责小字与红箭头从未进入视野**；
4. 反复清洗让参考帧越洗越脏（斑块成了下一次清洗的边界色）→ `full_ref2_v3/v5` **不可复用**。

## ✅ 现行方案 `rebuild_ref.py`（从原片重抽 → 一次性干净去叠加层）

**核心决定：不复用任何已清洗过的目录，一律从原片重抽。**
抽帧时刻取 `shots_all.json` 的 `kf`；三份产物 `full_ref2_v6/` `full_first6/` `full_last6/`。

叠加层**三类**，逐帧自适应检测（不依赖固定位置）：
| 类别 | 判据 |
|---|---|
| 字幕 | 亮字素（dy3 黄底黑边 / dy1·dy2 **白**底黑边）∩ `dilate(dark,2)`；行投影 → 跨行合并（gap 48） |
| 底部免责小字 | 同判据，独立成块 |
| 红箭头 | 纯红实心块，内部 std < 35（区别于有印刷纹理的红包装袋），面积 500–20000 |

**掩蔽方式：整块矩形 + `inpaint(TELEA, r=8)`。** 代价是"糊一块"，收益是**零字形**——
参考帧只做构图引导，字形残留的危害远大于一块模糊。

### 判据的三个必要约束（缺一个就误检/漏检）
1. **去大块白**：`white_raw=(s≤70,v≥170)` 必须减去 `OPEN(1×17)` 的结果，否则白衣服/白墙整片命中
   （dy3_s077 因此把 y 436–1261 全判成一块）；
2. **块内黑描边占比 ≥ 0.10**：字幕必有粗黑边，这是与白物区分的**关键**判据；
3. **宽度阈值 200 px**（不是 260）：4–6 字小字幕只有 ~250 px 宽，
   dy2_s003「小优她拖完了」就以 252 px 卡在 260 外漏检。

### 两个反复踩的硬坑
- **`kf` 下划线 = 小数点**：`frame-96_170s.jpg` 是 **96.170 s**。
  Python 3.6+ 的 `float("96_170")` **不报错**、返回 `96170.0` → 抽帧静默失败。必须 `.replace("_",".")`。
- **stroke（只掩字素笔画）对厚描边无效**：描边宽 5–8 px，掩码外沿仍落在描边上 → 填成**字形深灰块**
  （见 `_diag/FINAL_dy3_s054.jpg`）。**只能 rect。**
