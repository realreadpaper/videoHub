复刻要点导览（只读一次）

这一条的看家本领是误解与反转：先把观众想看的东西（后妈欺负孩子）老老实实演出来，再一巴掌翻过来。观众前期越恨这个继母，后期反转的情感收益越大，产品也就越自然地站在「善意」那一边。改写成你自己版本时，最该抄的就是这个信息差装置。

一句话故事核
18 岁生日前夕，继母看着像在欺负继女：使唤她拖地洗衣、拒绝她的生日请求、连她的 50 块钱都「抢」。孩子打给亲妈却被挂断。其实继母正偷偷去老巷子厨房求教，学着亲手给她做一碗红烧肉——生日那天，孩子改口叫了一声「妈」。
全片最强的设计：信息差
  • 继母被误解时不辩解——所有解释都是在曹阿姨面前说的，观众偷听到，孩子永远不知道
  • 只出现在声音里的亲妈，是「该负责却缺席」的对照组，比任何台词都更能让继母的付出有分量
  • 观众比剧中人先知道真相，才有「等她反转」的耐心
必须保留的骨架
  • 先立误解，再反转：观众需要一个误判对象，反转才有力量
  • 对照组：另一个「该负责却缺席」的人（这里是亲妈 + 软弱的父亲）
  • 产品即剧情必需：学做菜 → 用产品 → 做给人吃，是动作的一部分而不是插播
  • 风险对冲台词：先试吃、不满意退回
  • 情感落点要具体：不是「我爱你」，是一声改口
可以换掉的
  • 关系设定（继母 → 嫂子 / 婆婆 / 邻居 / 师父）
  • 节日或由头（18 岁生日 → 升学 / 出院 / 忌日 / 搬家）
  • 产品品类与赠品结构
  • 场景对（现代公寓 ↔ 老巷子厨房 → 老家 / 出租屋 / 医院）
