复刻要点导览（只读一次）

这一条是三条里结构最强、数据最好的一条，建议作为复刻的第一优先。它的核心不是「打脸」也不是「快切」，而是把产品写进了人物命运里——观众记住的是「这孩子回来接叔走」，不是「9块9七包」。复刻时最该抄的是结构，最不该抄的是原片的字幕（原片字幕烧死在画面里，本管线一律外挂）。

一句话故事核
被亲生父亲赶出门的男孩 → 被小饭馆的赵叔收留下来，靠一包红烧酱学到手艺 → 出去闯荡十年、只用同一款酱 → 回来给叔做一顿饭，接他走。
情感杠杆
  • 恩情闭环：受助 → 成长 → 回报，产品串在中间当载体
  • 同一动作重复三次（倒酱）完成「传承」的视觉表达
  • 让好人给产品背书（赵叔），比让推销员说好话有效得多
必须保留的骨架
  • 恩情闭环，结尾必须回到「报恩」而不是停在价格
  • 产品段挂在剧情动作上（「我给叔做菜」），不做独立插播
  • 产品作为「手艺传承」的载体跑完全片，不是救场工具
  • 第 7 幕卖点顺序照原片走（省事 → 电饭锅 → 脱骨 → 配料干净 → 一包多用 → 9.9 五包）
可以换掉的
  • 恩情类型（收留 → 救命 / 教手艺 / 借钱）
  • 时间跨度（十年 → 三年 / 一辈子）
  • 行业（小饭馆 → 面馆 / 早点摊 / 工厂食堂）
  • 产品品类与价格结构、赠品结构
制作注意（原片实测）
  • 平均 2.99s/镜，是三条里最慢的——情绪需要呼吸，别做成快切
  • 少年段是冷灰蓝（后巷、夜色、旧招牌），成年段转暖（店内灯光、酱色红亮）；色调与造型差异必须做出来，否则十年跳跃不成立
  • 少年段多用近景/特写（收留的亲密感），成年段中景与双人对峙
  • 原片字幕烧死（黄字黑边）+ 底部水印「剧情演绎 无不良引导」；本管线一律不烧字幕，字幕外挂同名 srt

  • ☐ 成片总时长控制在 5 分钟以内（原片 4:56），产品段不晚于 3:00 进入（原片 2:58）
  • ☐ 全片无任何字幕 / 文字 / 水印入镜；字幕单独外挂 srt/vtt，不烧在画面里
  • ☐ 产品镜必须走 <Picture 1> 参考图锁定，包装印刷与原图一致、清晰可辨
  • ☐ 三处「倒酱」动作的手部形态与料包外观必须一致（同一个动作重复三次）
  • ☐ 台词的卖点不超出原片：不加疗效承诺、不做绝对化表述、不加原片没有的赠品
