## 每份文档里有什么

| 区块 | 内容 | 怎么用 |
|---|---|---|
| 规格 + 使用方法 | 原片 ID / 时长 / 镜数 / 互动数据 / 产品段位置 | 开篇读一次 |
| **复刻要点导览** | 一句话故事核、情感杠杆、必须保留的骨架、可以换掉的、制作注意、**全片验收总则** | 只读一次，但每次开工前扫一遍 |
| **逐镜对照明细**（按幕分组） | 每幕给「本幕镜长序列 + 本幕台词全文 + 复刻要点 + 验收标准」；幕下逐镜卡片给**原片关键帧 + 估算景别 + 词级台词 + 验收标准** | 主战场。生成一镜 → 打开对应卡片对照 |
| 高风险镜挂牌 | ⚠️ 红牌镜：关键台词镜、价格镜、情感落点、转化指令镜 | 这些镜默认展开，先验它们 |
| 附录 · 全片逐镜表 | 全片 N 镜的起止 / 时长 / 景别 / 台词一览 | 排期、切段、算字幕轴时用 |

### 逐镜卡片里的四行

- **原片画面** — 原片该镜中时刻的关键帧，缩略图就是「这一镜长什么样」的答案
- **景别（估算）** — 用 OpenCV 人脸占比估的，只作定位参考；未检出人脸不代表没有人物
- **原片台词（本镜 · 词级）** — 从百炼词级时间戳切出来的，精确到这一镜说哪几个字
- **复刻 prompt** — **当前是占位**。改写方向（换产品 / 换脸 / 保留原设定）定了之后回填 H3 英文 prompt，这份文档就升级成《良心面试》那样的投产验收文档

## 当前版本的状态（重要）

这是**基准版**，不是投产版。差别只有一处：

- ✅ 已有：原片逐镜画面 + 台词 + 景别 + 逐幕复刻要点 + 验收标准
- ⏳ 待填：逐镜的**中文母版画面内容**与**英文 prompt**

所以现在能做的验收是「**复刻结果 vs 原片**」的对照验收（这台戏对不对、台词全不全、景别/节奏接不接近）；
等 prompt 回填之后，才能做「**复刻结果 vs 设计稿**」的投产验收。
