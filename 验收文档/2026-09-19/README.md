## H3 多人镜防糊（用户点名的问题）

H3 遇到多人镜容易画成**「三人同排」式的糊成一团**（所有人挤在同一平面、朝同一方向）。文档里的处理：

- **判定**：从 `framing.json` 的人脸计数自动识别，**≥3 张脸 = 多人镜**（04 有 15 个，05 有 37 个，05 最多一镜 6 张脸）
- **禁用**：`standing in a row` / `side by side` / `lining up` / `all facing the camera` / `group of people`
- **必写**：前景/中景/背景**分层**（谁近谁远）、每人各自的**朝向与视线落点**、**遮挡关系**、**焦平面**（浅景深只让一人清晰）
- 每张多人镜的卡片会自动挂一个蓝色「N 人同框」标记 + 位置逻辑要求；幕头显示本幕多人镜数量
- ★ **产品段与多人镜重叠的镜最危险**（04 #79/#85/#96/#99/#101；05 #56/#62/#65/#68/#85/#86）—— 这些镜必须写成「**产品在前景特写、人物在中景虚化**」，绝不能变成一群人围着产品排排站

| **逐镜对照明细**（按幕分组） | 每幕给「本幕镜长序列 + 本幕台词全文 + 复刻要点 + 验收标准」；幕下逐镜卡片给**原片关键帧 + 估算景别 + 词级台词 + 验收标准** | 主战场。生成一镜 → 打开对应卡片对照 |
| 高风险镜挂牌 | ⚠️ 红牌镜：关键台词镜、价格镜、情感落点、转化指令镜 | 这些镜默认展开，先验它们 |
| 附录 · 全片逐镜表 | 全片 N 镜的起止 / 时长 / 景别 / 台词 / 人脸数一览 | 排期、切段、算字幕轴时用 |

### 逐镜卡片里的几行

- **原片画面** — 原片该镜中时刻的关键帧，缩略图就是「这一镜长什么样」的答案
- **景别（估算）** — 用 OpenCV 人脸占比估的，只作定位参考；未检出人脸不代表没有人物
- **原片台词（本镜 · 词级）** — 从百炼词级时间戳切出来的，精确到这一镜说哪几个字
- **多人同框标记**（仅 04/05）— ≥3 张脸时自动挂出，附位置逻辑要求
- **产品特写要求**（仅 04/05，产品镜）— 该镜属于哪一级特写、必须拍到什么
- **复刻 prompt** — **当前是占位**。改写方向（换产品 / 换脸 / 保留原设定）定了之后回填 H3 英文 prompt，这份文档就升级成《良心面试》那样的投产验收文档

### 重新测人脸 / 景别（产出 framing.json）

```bash
cd ~/Desktop/videoHub/videos/douyin_refs/2026-09-19/7661791104643797617
# OpenCV Haar（正脸+侧脸+眼镜脸）→ 每镜 faces 数 + 人脸占比 → 供多人镜判定与景别估算
```
