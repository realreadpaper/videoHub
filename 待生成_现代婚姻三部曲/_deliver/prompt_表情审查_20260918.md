## 审查结论

1. **`<d>` 标签**：21/24 镜存在。该标签是 MiniMax H3 的 dialogue 指令，模型在驱动口型的同时，极易把标签内的中文字句渲染成屏幕字幕。建议全部替换为自然语言描述（如 `delivers the verdict in Chinese`）。

2. **表情僵硬根因**：
   - 大量 `spine straight / unnervingly calm / frozen in place / completely motionless` 等完全静态词；
   - 缺少 `jaw tighten / blink / swallow / lip tremble / muscle twitch / eyes narrow` 等微表情；
   - 缺少表情 transition（`flickering then vanishing / settles into / cracks`）。

3. **优化方向**：
   - 用'下颌收紧、嘴角微抽、缓慢吸气'替换'冷静/僵硬/不动'；
   - 给关键情绪转折加 transition；
   - 去掉 `<d>` 台词标签，依赖干声音频驱动口型。
