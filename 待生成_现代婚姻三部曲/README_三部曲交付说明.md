## 2. 为什么是 15 秒单镜（而不是 5 秒）

上一部《不可剥夺》是按 12 镜 × 5 秒做的。本次改为 **8 镜 × 15 秒**，依据是实测结论：

| 帧数 | 时长 | 帧差 MAE 最大值 | 判定 |
|---|---|---|---|
| 124 | 5.17s | 3.54 | ✓ |
| 243 | 10.12s | 1.66 | ✓ |
| **362** | **15.08s** | **2.48** | **✓ 零跳变（安全线）** |
| 413 | 17.21s | 40.94 | ✗ 7.0s 处跳变 |
| 719 | 29.96s | 46.68 | ✗ 10.2 / 20.1s 跳变 |

**账算下来是划算的**：8 镜 × 15 秒 = 120 秒成片，与 24 镜 × 5 秒总帧数接近，但

- 调用次数从 24 降到 8（模型切换固定开销省掉 2/3）
- 拼接接缝从 23 个降到 7 个
- **镜内连贯性天然更好**——一个完整的 15 秒表演镜头，胜过三段硬拼

判据说明：帧差 MAE 是逐帧计算的客观指标。正常连续镜头帧差在 **1~3.5** 平稳波动；出现 **>5 的孤立尖峰**即画面跳变。该阈值在 10 档样本上分布极干净（要么 <4，要么直接冲到 38~52），**比肉眼抽帧可靠得多**。

## 5. 字幕策略（2026-09-14 修订：**外挂交付，不烧进成片**）

**结论：成片不带任何字幕。字幕以独立外挂文件交付（`.srt` + `.vtt`），与成片同名同目录。**

这是本批与上一部《不可剥夺》最大的形态差异。上一部烧了两版（一版硬字幕、一版净化版），本次起取消硬字幕版。

**理由**

1. 烧死不可逆：平台送审、二创剪接、多语种都要能关掉字幕；
2. 模型自发字幕本来就是乱码，与其"清掉再补一层"，不如**根本不补**；
3. 改一个字不用重编码整片——外挂字幕改文本即可。

**为什么不再依赖模型出字幕**（《不可剥夺》踩过的坑）：

1. H3 会**随机**给台词镜烧中文硬字幕（12 镜只触发 1 镜）；
2. 即使用 Prompt 显式要求它出字幕，**渲染出来的常是乱码**（连换 3 个 seed 全乱码）；
3. 反过来说 `no subtitles` 也压不住它——所以 Prompt 里仍要写负向约束**尽力抑制**，但**不能指望它**。

**15 秒长镜带来的新问题**：想用 `silencedetect` 自动定位台词区间**行不通**。H3 生成的音轨是**连续环境音盖满**的——`-35dB` 阈值下检不出任何静音，带通 300–3000 Hz 人声频段也一样。环境音持续压在 -20 ~ -35 dB，人声没从中分离出来。

**处置**：15 秒长镜用**整镜内缩覆盖**（约 5% ~ 95% 时长）作为字幕时间窗，再按各镜在成片中的累计起点换算成绝对时间写入 SRT。

实现：`_后期/finish_film.py`。默认只出 **无字幕成片 + 外挂字幕**；`--burn` 才额外用 Pillow 渲染白字+黑描边透明 PNG，`ffmpeg overlay` 按时间窗烧一版硬的（绕开本机 homebrew ffmpeg **未编 `drawtext`** 的限制）。

**字幕也能完全脱离后期总装单独做** —— `_后期/make_subs.py`：

```bash
python3 _后期/make_subs.py --film 01_周星驰_三十八万八       # 常规
python3 _后期/make_subs.py --film 01_xxx --uniform 15.04      # 底片没拉回时按统一时长推算
python3 _后期/make_subs.py --check <片名>_字幕.srt --duration 120.34   # 只校验
```

两条硬规矩：**不依赖 Pillow**（本机 `/usr/bin/python3` 的 PIL 是 x86，Apple Silicon 上 import 即崩）；
**时间窗口径唯一真源**——`finish_film.py` 也从这里 import，避免外挂字幕与硬字幕两套口径。 **未编 `drawtext`** 的限制）。

**交付形态**

```
《片名》_全片.mp4        ← 主交付，画面无字
《片名》_字幕.srt        ← 外挂字幕（播放器 / 剪辑软件自行挂载）
《片名》_字幕.vtt        ← 同上，Web 版
```

## 5.5 模型乱码残字的清除（交付前必做）

Prompt 里写了 `no subtitles` 也压不住 H3 —— 它仍会**随机**给台词镜烧上中文硬字幕，而且**几乎全是乱码**：

| 片 | 镜 | 实际烧上去的（乱码） | 正确台词 |
|---|---|---|---|
| 01 | — | 无（8 镜全净） | — |
| 02 | shot01 | 把把唢呐给老子往死里吹 | 吹！把唢呐给老子往死里吹！ |
| 02 | shot04 | 这闺女今天维不出门坎 | 这规矩不能坏……这闺女今天绝不出门坎 |
| 02 | shot08 | 太阳眼常升起 / 走趿——! | 太阳照常升起！走喽——！ |
| 03 | — | 无（8 镜全净） | — |

01 与 03 两部的 16 个镜头全净——**说明抑制 Prompt（`no subtitles` + 负向约束）是有效的，02 部那次属于偶发漏网**。所以每部仍必须扫描，只是命中率不高。

而且这些字幕**会浮动**（模型做了下沉/淡入效果），不是钉在一处。

**为什么不能靠肉眼抽帧**：02 部第一次出的抽帧总览（每镜 1 帧、取第 6 秒）**漏掉了 shot01 和 shot04 的残字**——它们在 12~14 秒才出现。这就是《不可剥夺》那轮误判的同款陷阱。

**处置流程**（工具：`_后期/detect_residual_sub.py`，v3）

1. **扫描**：`PYPIL _后期/detect_residual_sub.py <片>/shots --frames 24`
   三重判据：横向长条（宽高比 ≥3.5）+ 填充率 5%~55% + **白像素梯度中位数 ≥12**。
   最后一条是决定性的：文字是 255↔0 的硬边（实测中位 **33~34**），而白婚纱/白墙/逆光高光只有 **2~3**（01 部 shot03 是白婚纱特写，v1/v2 判据都在这里误报，v3 才滤掉）。
2. **人眼复核**：命中项按 bbox 抽帧确认。命中的不一定是字幕——01 部 shot04 报的是**存折纸页的锐利白边**，予以排除。
3. **定位时间窗**：逐 0.5 秒扫一遍该 bbox，得出字幕出现的起止（如 shot08 是 2.0~15.0s）。
4. **delogo 清除**（支持 timeline，只在字幕出现的时间段抹，别的帧不动）：
   ```bash
   ffmpeg -i in.mp4 -vf "delogo=x=451:y=662:w=441:h=62:enable='between(t,12.4,15.1)'" \
     -c:v libx264 -crf 16 -preset medium -pix_fmt yuv420p -c:a copy out.mp4
   ```
5. **产物放 `shots_clean/`，不覆盖原片**。`finish_film.py` 会自动优先取 `shots_clean/shotNN.mp4`，并在启动时打印「已启用清理版镜头」。
6. **复检**：对 `shots_clean/` 再扫一遍，确认归零。

## 6. 音轨响度

各镜由模型独立生成，**电平天然不齐**。合成阶段必须做 **两遍** `loudnorm`：

```bash
# ① 第一遍：测真实响度，读 JSON
ffmpeg -i raw.mp4 -af loudnorm=I=-16:TP=-1.5:LRA=11:print_format=json -f null -
# ② 第二遍：把 measured_* 填回去精确归一（视频流直通，只重编音频）
ffmpeg -i raw.mp4 -c:v copy -af "loudnorm=...:measured_I=...:measured_I=...:linear=true" -c:a aac out.mp4
```

**单遍 loudnorm 是动态模式靠估计，实测只能到 -18.5 LUFS**（目标 -16，差 2.5 dB）。两遍法可精确咬到 **-16.3 LUFS / -1.5 dBTP**。

## 8. 已知限制

1. **单镜安全上限 15.08 秒**。17 秒起必然跳变。人物特写是最敏感题材，动作/多主体镜头余量更小。
2. **角色一致性靠 Token 复述 + 同 seed，不是锁脸**。本批 07/08 镜的角色描述相比 01–06 略有简化，是 QC 重点。
3. **模型偶发乱码硬字幕**：Prompt 里写了 `no subtitles` 也压不死，交付前必须逐镜抽检无字幕版成片；被烧上乱码的镜要用 `delogo` 抹掉（`01_周星驰_三十八万八` 这 8 镜实测干净，无残留）。
   - 注意区分**剧情道具上的文字**（如 shot02 门缝递出的纸条写着「388000 yuan parking slot fee」）——那是剧本要求的画面内容，不是字幕，不要抹。
4. **台词为模型原生生成**，个别字可能音近而非精确；不达标时只需重跑该镜。
5. **批量峰值显存会爬到 22.2 GiB**（单发测试只有 20.7）。24 GiB 卡跑 362 帧批量有 OOM 风险。
