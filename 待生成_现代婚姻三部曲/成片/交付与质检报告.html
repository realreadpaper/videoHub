工具口径踩坑（已记录）：qc_shot_analyzer.py 的「MAE > 22.5 = 硬切」阈值是拿单 beat 连续镜标定的。 三部的 prompt 每镜都写成 3 个 5 秒 beat： 
[00:00.000 – 00:05.000] … [00:05.000 – 00:10.000] … [00:10.000 – 00:15.000] …
模型把 beat 当独立镜头渲染，所以 15 秒「单镜」实际是 2–3 镜头的小剪辑段，切点大致落在 beat 边界（实测 5.08 / 5.17 / 5.29 / 5.33 / 7.08 / 8.79 / 10.75 / 12.38 / 13.46 s…），但不精确对齐 5.000 s。 因此这 36 处告警在 3-beat 剧本下是预期行为，不是缺陷；反向也说明：要卡准剪辑点，得改 prompt 的 beat 写法，而不是改模型。

3.2 有效分辨率探针（PSNR，越低 = 真实高频越多）

三部 24 镜在 1008px 档落在 45.9–51.6 dB。偏低（更清晰）的是 02 部 shot06/07 与 03 部 shot05（42–47 dB），对应毛领质感、暗部雨夜等高细节画面；偏高的是对话近景与纯色背景镜。整片无「糊成一片」的异常镜。

3.3 锐度（拉普拉斯方差）

同内容内可比：静镜 3–30，细节镜 50–113。波动来自画面内容（景别/运动模糊），不是清晰度漂移。三部之间无系统性差异。

部集成响度响度范围 LRA真峰值判定

根因：脚本用的是单遍 loudnorm。 
"-af", "loudnorm=I=-16:TP=-1.5:LRA=11"
单遍是动态模式，按各片自己的增益轨迹走，三部素材动态差异大 → 结果散成 -14.2 / -15.6 / -18.6。 ② 部真峰值 -0.6 dBTP 已经越过 -1.5 的红线（部分平台会削波），③ 部 LRA 20.1 LU 也过大。 走两遍 loudnorm（第一遍测、第二遍带 measured 参数应用）可稳定收到 -16.3 LUFS / -1.5 dBTP —— 这是既有交付链 finish_film.py 的做法。
