一、结论：能用，而且不用改管线架构

你手上这个模型本身就是为这件事设计的 —— 图条件能力一直没被打开过。

片1 那 20 个镜全部是「纯文生视频 + 音频锁定」（T2VA）：只喂文字 prompt 和中文干声， 模型对产品长什么样一无所知，只能按 prompt 里那句「袋面空白无字」画一个纯红空壳。 这就是「产品样子不对」的根因，而不是参数没调好。

而现有工作流里的 MiniMaxH3AudioConditioningT8 节点， input 列表里一直躺着 first_frame 和 last_frame 两个图像槽，从来没有接线 （link = None）。把真产品图合成进关键帧、接上这两个槽， 生成出来的袋面就天生是那张产品图 —— 透视、光影、材质由模型自己渲染， 不再需要事后逐帧抠图。

二、机制：这不是外挂技巧，是模型的原生能力

证据链（都在你自己的仓库里，可逐条复核）

权重文件名 minimax_h3_fl2va_pruned_int8_convrot.safetensors
fl2va = First-Last frame to Video + Audio。 这个权重的作用域就是「首/尾帧 → 视频+音频」。 节点输入槽 _remote/stage1_voice_film1_s13.json 节点 6 的 inputs： … / 5 final_audio / 6 first_frame / 7 last_frame， 后两个 link: None —— 官方模板留的接口，一直空着。 官方规范 FLF2V 提示词写法明确要求：端点图像已经回答了「呈现什么内容」， 提示词只需说明中间「如何运动」，不要重复描述视觉细节，否则会与固定帧冲突。 ——这条直接决定了 prompt 要怎么改（见第六节）。
真产品图→ 合成进关键帧→ 接 first_frame 槽→ H3 生成（模型自己渲染袋面）→ 成片里袋面就是真包装

四、哪些镜能用 —— 可行性由素材决定，不由配置决定

关键帧只能是 t=0（首帧）或 t=14.9（尾帧），所以判断依据很硬： 那一帧画面里有没有袋子。逐帧核过片1 三个产品镜：

镜t=0 帧t=15 帧能否锚定说明
13 整屏产品特写（红壳） 厨房场景，无袋 △ 机制上可，但不建议 这个「镜」内部 0–1s 是产品特写、1s 后切大厅、9s 后切厨房。 首帧锚定会与分段描述直接打架（首帧是产品，prompt 说这 5 秒在拍人物对话）， 模型有把整镜都画成产品特写的风险。要用就得重写分段。
15 女生站立说话，无袋 锅里炖肉，无袋 ✗ 不可 袋只在镜中段 6.0–10.5s 出现（这是后处理贴图实测出来的）。 H3 只有首/尾两个锚点，没有中间帧锚定 → 保持后处理贴图。
18 双手持袋、袋面可见 手持袋、袋在下方 ✓ 建议首锚 最干净的验证案例：t=0 就是手持产品，与 prompt 第一段 （“S2 holds the red pouch up in both hands”）完全一致，没有结构冲突。
比「改造现有镜」更值得做的一件事：新增一条「产品特写插入镜」。
用真产品图特写当 first_frame、另一个角度当 last_frame， prompt 只写运镜（官方推荐的产品展示写法：缓慢匀速 30 度环绕，高光沿表面滑过，全程无剪辑）。 这样产品以最高保真出现，又完全不牵扯原有分镜结构 —— 放在卖货段（镜18 附近）正好补足「产品露出不够」的短板。

六、prompt 必须同步改 —— 这是最容易翻车的一步

硬矛盾：现有 prompt 的 STYLE 尾巴里写着 completely empty, smooth, blank and unprinted 和 no lettering, no numbers, no symbols, no logo and no barcode， 还要求「画面里任何包装/印刷面都是空白」。 而锚定用的首帧里，袋面本来就有真包装印刷 —— 两条指令直接打架， 结果是模型要么把印刷抹掉（退回空壳），要么画出混乱的字。

按官方 FLF2V 规范（端点图像负责「是什么」，提示词负责「怎么动」），做了隔离式改造：

新增常量作用只对谁生效
SP_ANCHORED 产品锚定不再描述「红区空白无字」，改为「袋面带有自己的印刷包装，结构与首帧一致，整镜保持不变」 仅 anchored=True 的镜
片1 目前只有镜18；其余 19 镜的 prompt 一字未动
NO_TEXT_CLAUSE_ANCHORED 把「实物包装必须空白」和 no logo 两条豁免掉； 禁字幕条 / 标题 / 角标 / 卡拉OK / 水印 / 时间码 / UI / 任何悬浮叠字 —— 一字不动全保留， 并要求包装印刷保持「平、哑光、略虚，不许比实物更亮更粗」
STYLE_ANCHORED 风格尾巴的锚定版，由 build.py 按镜自动选用
_ANCHOR_NOTE 在 prompt 里加一句「从给定首帧开始，保持构图/光线/色彩/袋面印刷，只演化描述的动作，不要重演开场」

禁字铁律的终检依然生效且已验证：build.py 的 NO_TEXT_ANCHORS（no subtitles / no captions / no on-screen text / never imitate or reproduce a subtitle strip）在锚定版里全部保留，缺一即拒绝生成。 即：豁免的只是「实物自带印刷」，不是「画面叠加字幕」。

八、风险与验收

风险清单（按严重度）

  1. 袋面印字被临摹成乱码 —— 这是新引入的主要风险。 缓解：锚定版条款已要求印刷「平、哑光、略虚、不许更亮更粗」； 验收时看袋面字是否成行可读。观众对包装上的字容忍度远高于 「画面中飘一行字幕」，量级不同。
  2. 首帧锚得过死：模型可能整镜都保持首帧构图、不动。 缓解：_ANCHOR_NOTE 已明确「只演化描述的动作」； 镜18 的首帧正好是 prompt 第一段的姿态，风险最低。
  3. widget 索引错位（未经实测的部分）→ 用 probe_h3_nodes.py 先核。
  4. lock_source 与图条件并用是否互斥 —— 文档未明确，需实测一镜确认。

验收标准

  • 袋面文字是真品牌/品名/价格，无成行乱码
  • 无新增叠加型字幕/标题/水印（沿用 scan_text_band.py 接触表逐格扫）
  • 物体运动正常，没有「冻结在首帧」的僵硬感
  • 与未锚定镜拼接后，产品外观在同一片里一致
  • 目标时长不变（锚定不改帧数，仍是 362 帧 / 15.0833s）
