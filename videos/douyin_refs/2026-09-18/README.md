## 目录约定

```
videos/douyin_refs/YYYY-MM-DD/
├── <视频ID>.mp4            原始视频（1080p，下载自抖音 CDN）
├── metadata.json           三条视频的元信息（描述/时长/互动数据/直链）
└── <视频ID>/
    ├── audio_16k.wav       提取音频：16kHz 单声道 PCM（ASR 用）
    ├── audio_16k.mp3       同上，mp3 压缩版（上传/分发用）
    ├── <视频ID>.srt         字幕（句级时间戳，可直接外挂播放）
    ├── transcript.txt       全文纯文本
    ├── asr_raw.json         阿里云百炼原始返回（含**词级**时间戳，可复用）
    ├── boundaries.json      逐帧变化候选（镜头边界检测原始输出）
    ├── shots.json           镜头表（镜号/起止/时长，阈值 0.15）
    ├── shots.md / shots.csv 逐镜脚本表（词级对齐：每镜说什么）
    ├── shots_dialogue.md    台词分句表（句级时间戳）
    ├── segments.md          叙事段落表（一段=一个说话回合，含镜数与镜长序列）
    ├── ANALYSIS.md          整片解读（结构/人物/视觉/产品植入/复刻要点）
    ├── TIMELINE.md          时间轴拆解（分段+镜头号+台词+设计意图）
    ├── keyframes/           逐镜关键帧（155/119/99 张，文件名=镜中时刻）
    └── evidence/
        ├── overview/        全片概览网格（每片 2 张）
        └── calib_0_20.jpg   开头 20 秒逐秒校准网格（766445 那条）
_tools/                      本次使用的脚本（可复用）
```

## 三条共同的产品话术骨架

1. **痛点**：不会做饭 / 怕油烟 / 炒糖色麻烦 / 上班累想点外卖
2. **方案**：一包酱 + 电饭锅，加水按煮饭键
3. **验证**：挑食的孩子 / 挑剔的老人吃光；筷子一戳脱骨
4. **价格**：9.9 元 5–7 包，一包一块多，比买瓶酱油还便宜
5. **对冲**：赠试吃包，不满意可退（第 2 条讲得最细）
6. **指令**：点左下角下单 / 进橱窗

  → 对复刻的提示：**慢一点、把产品写进人物命运里，比堆快切和打脸更有效。**
- 三条都控制在 5 分钟以内，产品段都在 80–110 秒（占 27%–37%）。
- 三条的字幕都**烧死在画面里**（黄字黑边，关键信息放大），
  复刻时若要外挂字幕需要先处理原字幕。

## 复用说明

- `_tools/asr_pipeline.py`：本地音频 → 百炼 OSS → paraformer-v2 → SRT + 词级 JSON
- `_tools/build_shots.py`：边界候选 → 镜头表（可调阈值）
- `_tools/merge_shots_words.py`：镜头 × 词级转写 → 逐镜脚本表
- `_tools/build_segments.py`：镜头 × 句级转写 → 叙事段落表
