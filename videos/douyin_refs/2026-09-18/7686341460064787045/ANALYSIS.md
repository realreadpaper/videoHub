## 这一条是什么

**「被误解的继母」+ 生日一碗红烧肉**的情感反转剧。全片最大的设计是
**把观众想看的东西（后妈欺负孩子）先演出来，再一巴掌翻过来**——
观众前期越恨这个继母，后期反转的情感收益越大，产品也就越自然地站在"善意"那一边。

产品段在 2:36–3:35，**夹在"学做菜"和"端菜给孩子"之间**：
莫姨向曹阿姨学做菜，学到产品的用法 → 顺带讲完卖点 → 回到剧情去做给女儿吃。
植入不是插播，而是**剧情必需的一步**。

## 人物与表演

- **小优（18 岁）**：全片视角人物。她的委屈不喊不闹，只是不断低头、
  被使唤、被挂电话——**越安静越有效地把"她值得被爱"这件事立住**。
- **莫姨（继母）**：前 1 分钟是"恶人"，1:12 之后全部翻案。她的表演关键在于
  **被误解时不做辩解**：所有解释都是在曹阿姨面前说的，观众偷听到，
  孩子永远不知道——这是反转类短剧的标准信息差打法。
- **老王（父亲）**：典型的"软弱在场"——夹在中间，既给不了钱也给不了陪伴。
  他的存在让"继母成为唯一行动者"显得必要。
- **曹阿姨**：工具人兼背书人。她的"秘方不外传"→"罢了，你既是个当妈的苦心"
  这句转口，是把产品合法性交出来（**连老手艺人都用**）。
- **亲妈（电话里）**：功能是"对照组"。一个只出现在声音里的亲妈，
  比任何台词都更能让继母的付出有分量。

## 复刻要点

**必须保留的骨架**
1. **先立误解再反转**：观众需要一个"误判"对象，反转才有力量
2. **对照组**：另一个"该负责却缺席"的人（这里是亲妈/父亲），衬托行动者
3. **产品即剧情必需**：学做菜 → 用产品 → 做给人吃，产品是动作的一部分而非插播
4. **风险对冲台词**（先试吃、不满意退回）
5. **情感落点要具体**：不是"我爱你"，是一声改口的"妈妈"

**可替换的**
- 关系设定（继母 → 嫂子 / 婆婆 / 邻居）
- 节日或由头（18 岁生日 → 升学 / 出院 / 生日 / 忌日）
- 产品品类与赠品结构
- 场景对（现代公寓 → 老家 / 出租屋 / 医院）

**制作注意**
- 前段冷调、后段暖调的双调色是本片的记忆点，复刻时别做成同一套色调
- 平均 2.4s/镜，比同批的 7664454812574337402（1.92s）**慢一档**，
  情绪戏留得住；复刻时前 1 分钟可以更碎，厨房段要敢给长镜
- 产品段有一组并排展示多包的构图，属于必要露出，别省
