## 这一条是什么

**「霸总/女总裁家的挑食女儿」+ 神酱救场**的带货短剧。剧情占前 3 分 35 秒，
最后 1 分 20 秒由一个"奶奶"角色把产品讲透，落在"9块9 七包 · 点左下角下单"。

它不是在讲故事，是在**用故事给一个"不会做饭的人也能做出大厨味"的承诺做担保**。
所有剧情设计都服务于一个转化点：让观众相信"连这么挑剔的孩子都吃了 → 我也能行"。

## 叙事结构

| 段落 | 时间 | 功能 |
|---|---|---|
| ① 冲突建立 | 0:00–0:53 | 女儿不吃饭、三个月换 9 个厨师、顾总发火 → **一个问题摆在桌上** |
| ② 意外英雄登场 | 0:25–1:06 | 女儿偷跑出门，被一个陌生小伙子用一块饼救了 → 反差人物 |
| ③ 被质疑 | 0:53–2:19 | 到顾宅被管事和主厨围攻"来路不明""路边摊" → 制造需要被证明的悬念 |
| ④ 权威反转 | 1:35–2:01 | 顾总亲自查出：小伙子迟到是因为在路边扶起晕倒的女儿 → **人品先立住** |
| ⑤ 赌局 | 2:01–2:19 | "她吃你留，她不吃你也走" → 极低容错，抬高风险 |
| ⑥ 打脸 | 2:19–2:57 | 只倒一包酱，被老厨师嘲"我学了15年颠勺不如一包酱" → 情绪压到最低点 |
| ⑦ 验证 | 2:57–3:24 | 女儿吃光、半年第一次自己动筷子 → **情绪释放** |
| ⑧ 产品段 | 3:37–4:33 | "奶奶"背书 + 电饭煲演示 + 9.9 元七包 + 左下角下单 |
| ⑨ 情感收尾 | 4:45–4:57 | 拉钩、"你负责吃饭我负责做饭" → 回到人物关系,不让整条片变纯广告 |

**关键判断**：产品在 3:37 才第一次正式登场，前面 3 分半**一句卖点都没提**。
这不是失误，是这类带货短剧的标准打法——先把"挑剔的孩子吃光"这个事实演出来，
观众的情绪信用攒够了，再拿产品去兑换。

## 人物与表演

- **顾总（女总裁）**：黑衬衫、盘发、全程冷静但压迫感强。她的功能是"权威裁判"——
  她说"留下"，观众才认这个结果。
- **女儿（约 6 岁）**：全片的"证据"。她的表演只有两个状态：拒绝吃 / 大口吃，
  落差就是卖点。
- **小伙子（男主）**：白衬衫、干净、话少。典型的"被低估的老实人"设定，
  他不需要多说话，被围攻时低头、做菜时专注就够。
- **赵师傅（原主厨）**：反派功能位。他那句"我学了15年颠勺，合着不如一包酱"
  是整条片**最重要的一句台词**——它把观众的自我怀疑（"我不会做饭"）说出口了,
  后面用产品解掉。
- **楠奶（老太太）**：产品段背书人。选老人做背书，是因为她天然带"做饭几十年"的
  可信度，与"这酱到底行不行"的质疑直接对上。

## 视觉与声音

- **画面**：竖屏 1080×1920，暖调室内，餐厅/厨房实景；人物特写为主，
  换人即换镜，靠正反打推进对话。
- **运镜**：以固定机位和轻微推拉为主，极少运动镜头——低成本、高剪辑密度。
- **字幕**：**烧死在画面里**，黄字+黑描边，位置固定在画面下方三分之一。
  有意思的是大字幕常把当句关键信息放大（"三个月9个厨师""我亲自把关"），
  相当于给观众划重点。
- **水印**：底部"剧情演绎 无不良引导"——平台合规要求的短剧标识。
- **声音**：全片人声干声为主，无配乐段落或轻bed，靠对话节奏带节奏。

## 复刻要点（要保留什么 / 可以换什么）

**必须保留的骨架**
1. "挑剔的嘴"作为验证器——孩子/老人/病人这类"不会给面子"的角色最有效
2. 权威角色的裁决（这里是顾总），没有裁决就没有结果的可信度
3. 专业人士的质疑台词（"我学了15年"）——这句是给观众泄压的
4. 产品晚出场：前半段只演问题，不卖货
5. 结尾回到人物关系而非价格

**可替换的**
- 场景（餐厅 → 家 / 医院 / 办公室）
- 产品品类（红烧酱 → 其他"一包搞定"型调味品）
- 背书人身份（奶奶 → 退休厨师 / 邻居阿姨）
- 价格档位与赠品结构

**制作注意**
- 全程平均 1.9s/镜，AI 生成时要按短镜写 prompt；长镜超过 5s 只有 2 个
- 字幕是烧死的，复刻时若要外挂字幕，需从画面上抹掉原字幕（本片大字幕信息量大，
  抹除后需整片重配字幕）
