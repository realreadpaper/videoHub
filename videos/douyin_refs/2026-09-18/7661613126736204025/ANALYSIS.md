## 这一条是什么

**「被抛弃的男孩 + 一碗红烧肉的恩情」+ 十年后回来接恩人**的因果闭环剧。
它比同批另外两条更"正剧"：**产品在这里不是救场的工具，而是恩情的载体**——
十年前那包酱是收留他的方式，十年后他还在用同一包酱，产品就等于这个人的人品。

数据明显更好的原因大概在此：**它把带货做成了一个完整的因果故事**，
观众记住的是"这孩子回来接叔走"，不是"9块9七包"。

## 叙事结构

| 段落 | 时间 | 功能 |
|---|---|---|
| ① 弃 | 0:00–0:14 | 亲生父亲亲口驱逐："你就是个拖累" → 主角一无所有 |
| ② 收 | 0:14–0:47 | 老赵把蹲在后门口的他带进屋、擦药、端出红烧肉 → 恩情成立 |
| ③ 传 | 0:47–1:22 | 留下帮工、教拿刀、教"这包酱"→ 产品作为手艺传承进入剧情 |
| ④ 出去 | 1:22–1:41 | 男孩要出去闯，老赵塞酱：「想家的时候就炖个肉」 |
| ⑤ 成 | 1:41–2:04 | 十年后，他成了周总，店里十年只用同一款酱，供应商续约 |
| ⑥ 回 | 2:04–2:58 | 回老店看叔，用同一包酱做给叔吃，"味道稳住了" |
| ⑦ 产品段 | 2:58–4:19 | 从"我自己的做法"自然切到口播卖点 + 9.9 五包包邮 |
| ⑧ 接 | 4:19–4:56 | "当年您接我进来，现在换我接您走" → 因果闭环 |

**它最聪明的一步**：产品段（2:58–4:19）不是插在剧情之外，
而是**借"小周回来给叔做菜"这个动作展开的**。观众此刻已经完全站在产品这一边——
因为对观众来说，否定这个酱就等于否定这份情。

## 人物与表演

- **小周**：全片唯一的成长线。少年段落（破T恤、脏脸、低头）与成年段落
  （西装、发型、从容）几乎不用台词区分，**靠造型和姿态完成十年跳跃**。
- **老赵（叔）**：恩人。他的表演核心是"少说多做"——擦药、递肉、教刀、
  塞酱，四件事全是动作。他给产品背书时不需要说服观众，
  因为观众已经认定他是个好人。
- **亲生父亲**：只在开头出现，一句话完成驱逐。**越简短越残酷**。
- **供应商/店长等配角**：功能是给"这家店十年只用这款酱"提供旁证。

## 复刻要点

**必须保留的骨架**
1. **恩情闭环**：受助 → 成长 → 回报，产品串在中间。这是三条里最强的结构
2. **同一动作重复三次**（倒酱），用重复完成传承表达
3. **恩人给产品背书**：让好人说好话，比让推销员说好话有效得多
4. **产品段挂在剧情动作上**，不做独立插播
5. **结尾必须回报**，不能停在价格

**可替换的**
- 恩情类型（收留 → 救命 / 教手艺 / 借钱）
- 时间跨度（十年 → 三年 / 一辈子）
- 行业（餐馆 → 面馆 / 早点摊 / 工厂食堂）
- 产品品类与价格结构

**制作注意**
- 平均 2.99s/镜，是三条里最慢的，**情绪需要呼吸**；
  少年段和成年段要做出明显的色调与造型差异，否则十年跳跃不成立
- 产品段有"进橱窗抢一单"这种强转化话术，同时保留"让更多人吃上一口好饭"的
  情感包装，两者必须同时在场
- 结尾是双人对话收束，需要给足两个角色的近景
