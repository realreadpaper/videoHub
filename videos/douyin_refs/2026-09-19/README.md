## ★ 本次最重要的技术发现

### 一、镜头边界阈值：**必须看候选分数分布，不能按内容类型套**

**部分真实硬切的分数极低**（实测低至 **0.046**），而 `hypit media boundaries`
默认 `--threshold 0.1` **会在源头把这些点过滤掉**，只调 `build_shots.py` 救不回来。

本次三条**全部采用 `--threshold 0.04 --rate 12` 重跑**。以面试那条为对照：

| 阈值 | 镜数 | 平均镜长 | 20–40s 切点 |
|---|---|---|---|
| **0.04** | **113** | 2.53s | 6 个（与目视吻合 ✅） |
| 0.1 | 97 | 2.95s | 把 20–25s 的 3 镜并成 1 个 4.3s 长镜 ❌ |
| 0.15 | 89 | 3.21s | 同上 ❌ |

**判据**：`build_shots.py --threshold 0.15`（沿用长视频经验）在**对白驱动、正反打密集的
短剧上会明显漏切**。**这类内容一律从 0.04 起试**，并用 **0.5s 密度网格**做目视校准
（逐秒网格太粗，看不出 1s 级切点）。

### 二、AI 短剧会用「镜内渐变变形」代替剪辑

7678941440429033137 的 0:49–1:01 有一个 **12.17s 长镜**，内部完成
「现实 → 白雾回忆 → 接吻 → 变形回现实（奶牛）」三次场景跳转，**全程无硬切**。
这是 `#ai短剧` 特有手法，**不是脚本漏切，别人工切开**。

### 三、两类内容的本质差异

| | AI 短剧 | 带货短剧 |
|---|---|---|
| 台词密度 | 450 字 / 163s = **2.8 字/秒** | 2005 字 / 286s = **7.0 字/秒** |
| 纯画面镜 | 16 个（23%） | **0 个** |
| 驱动方式 | 独白 + 视觉 | **纯对白正反打** |
| 关键指标 | 分享率 60.4% | **收藏率 30%** |
| 产品段 | 无 | 固定模板，可跨片复用 |

**带货短剧 0 个纯画面镜**——复刻时插入任何慢镜/空镜都会塌节奏。

### 四、同产品两条片子的模板复用（重要）

`7661791104643797617` 与 `7663019839170397945` 是**同一产品（爆汁红烧酱料）的两条片子**，
故事完全不同，但产品段口播的**段落顺序、句式、价格结构逐句对应**：
痛点 → 电饭锅颠覆 → 三步做法 → 脱骨验证 → 只洗一个内胆 → 比价 → 9.9 元 7 包包邮。
唯一差异是各自主打一个不同卖点（面试版"孕期可吃" / 相亲版"**零蔗糖**"）。

→ **产品段是固定脚本，换片时只调 1–2 个卖点即可**，避免观众"刷到同一条广告"的疲劳。
