**结构判断**：这是标准的 **「测试段 2/3 + 产品段 1/3」** 带货骨架。真正值得抄的不是剧情，而是**产品的入场方式**——产品不是在第 3 分钟"开始打广告"，而是**在 1:19 就已经作为"善举的载体"出现过一次**：女主角分给陌生老人的午饭，就是用电饭锅 + 这包酱做的。

观众在 1:19 听到"爆汁红烧酱料"这五个字时，接收到的信息是"这姑娘真善良"；等到 2:58 产品段开始讲做法，观众心里已经给这个产品记了一笔**情感账**。这是整条片子最省力的设计。

## 三、人物与表演

| 角色 | 功能 | 负责的情绪 |
|---|---|---|
| **顾怀山**（董事长，假摔老人） | 测试者 / 揭示真相者 | 权威裁决感 |
| **面试者 A**（主管岗男） | 淘汰者 1 | "你别挡我前途"——**利己** |
| **面试者 B**（行政经理女） | 淘汰者 2 | "公司不是救助"——**刻薄** |
| **林婉晴**（面试食堂厨师助理） | 通过者 / 产品演示者 | 善良 + 手艺 |

**表演设计**：两个淘汰者的台词承担全片的**情绪债**制造——"你赔得起吗""你饿关我什么事儿"。观众被冒犯得越具体，后面好人通过时的释放越足。这两位的存在**不是浪费时长，是给产品段蓄势**。

**身份反差**：董事长穿着旧外套、坐轮椅、手上都是灰——**他的落魄程度直接决定测试的可信度**。扮得太体面，测试就失效。

## 五、产品植入表

| 时点 | 形态 | 内容 |
|---|---|---|
| **1:19** | 台词提及 | "真不是我厨艺多厉害，是这个爆汁红烧酱料太省事"——**藏在善举里** |
| 1:30 | 做法简述 | "排骨焯水后放电饭锅，倒一包酱料加半碗水，按煮饭键" |
| **2:58–4:31** | 完整口播段 | 痛点 → 做法 → 卖点 → 价格 → 促单（93 秒，占 32%） |

**口播骨架**（可直接复用为模板）：

1. **痛点**：下班累到散架，想吃硬菜又不想切葱姜蒜、忍油烟炒糖色，还要刷油腻炒锅 → 干脆点外卖
2. **颠覆**：只要有个电饭锅，饭店级软烂红烧排骨闭着眼睛做
3. **排除干扰**：八角、桂皮、酱油、老抽统统靠边站
4. **三步做法**：排骨焯水 → 扔进电饭锅 → 撕一包酱料 + 半碗水 + 按煮饭键
5. **验证**：色泽红亮、筷子一戳脱骨、只洗一个电饭锅内胆
6. **安全性**：配料表干净，老人小孩孕期可吃
7. **延展性**：红烧肉、红烧鱼、炖肉一包全搞定
8. **比价**：超市一包七八块
9. **价格**：9.9 元 5 包 + 自掏腰包送 2 包 = **7 包**，折合一块多一餐
10. **促单**：库存见底、点击左下角头像抢单

**结尾金句**："一个人能不能留下，不只看简历" → "手艺可以慢慢练，产品可以慢慢学，**良心不能没有**" —— 把产品从"调料"提到"良心"层面，完成情绪收口。

## 六、复刻要点

### 必须保留

1. **测试结构**：同一道考题，多个陌生人依次作答，前败后成。**失败者要占足时长**（本片前两人占了 58 秒，超过 1/5），牺牲他们来给成功者加权。
2. **产品藏在善举里**：好人施善时，产品必须**作为道具在场**（这里是"分给老人的午饭"）。这是全片最高效的一笔。
3. **反派台词要具体、要难听**。"你饿关我什么事儿"比"他很冷漠"有效十倍。
4. **揭身份的反转放在 2/3 处**（2:01），给产品段留足 1/3 的空间。
5. **结尾金句 + 反问**（"你们说对吗？"）——拉动评论区，成本为零。

### 可替换

- 测试场景：职场面试 → 相亲 / 邻里 / 租房 / 校园，**只要"陌生人需要帮助"成立即可**。
- 被测试者人数：本片 3 人，2 人是最低配（一败一成）。
- 产品品类：只要能塞进"施善场景"（食物最省力）。
- 品牌名可换（本片"顾氏食品集团"为虚构设定，与真实品牌无关）。

### 制作注意

- **每镜都有台词**（113 镜 0 个纯画面镜）——这是**对白驱动**的短剧，不是视觉驱动的。复刻时不要设计"无台词炫技镜"，会拖节奏。
- 转写文本里的错字按画面修正（**ASR 原文不改**）：怕丹泽→**怕担责**、古董→**顾董**、鬼皮→**桂皮**、内躺→**内胆**、拼手速、炖驴→**炖肉**。
- 竖屏构图下**人物近景为主**，产品特写用红色箭头补足信息，不需要专门留"产品大特写"镜头。
